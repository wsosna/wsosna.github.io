# wsosna.github.io

My personal page, built with [Astro](https://astro.build) and deployed to GitHub Pages.

## Run it locally

Requires Node 22 or newer and [pnpm](https://pnpm.io).

```sh
pnpm install
pnpm dev        # http://localhost:4321
```

To check the production build:

```sh
pnpm build && pnpm preview
```

Pushing to `main` deploys the site.
